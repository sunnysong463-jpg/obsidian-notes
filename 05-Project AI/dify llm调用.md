## 二、第 1 步：登录 Manus，进入「工作台」

1. 打开：[https://manus.im](https://link.wtturl.cn/?target=https%3A%2F%2Fmanus.im&scene=im&aid=497858&lang=zh "autolink")
2. 登录你的账号
3. 进入 **Workspace（工作台）**

## 三、第 2 步：先建一个「可重复用的分析任务模板」

这一步只做一次，以后自动跑就用这个模板。

1. 点右上角 **+ New Task**
2. 在任务框里写**清晰的指令**（直接复制下面，改改就行）：

plaintext

```
你是亚马逊广告运营专家。
我会上传最近7天的广告报表（CSV）。
请自动做以下分析：
1. 找出点击率最高/最低的关键词
2. 找出ACoS最高/最低的广告组
3. 找出花费高但无转化的词
4. 给出5条可直接执行的优化建议
5. 输出成表格+文字报告，方便复制到Excel
```

3. 上传**一份你的广告报表（CSV）**（先手动跑一次，确认能出结果）
4. 点 **Run**，等 Manus 跑完（第一次手动，测试用）
5. 跑完后，**确认结果正常** → 这个任务就成了你的「模板」

---

## 四、第 3 步：把这个任务变成「自动运行」（关键！）

Manus 有个功能叫 **Scheduled Tasks（定时任务）**Manus，就是：

**到点自动跑任务、自动用新文件、自动出报告。**

### 操作：

1. 回到 Manus 首页
2. 点 **Settings（设置）→ Scheduled Tasks（定时任务）**Manus
3. 点 **+ Create Schedule**
4. 填写：
    
    - **Task Name**：亚马逊广告每日分析
    - **Frequency（频率）**：每天（或每周一）
    - **Time（时间）**：比如每天早上 8:00
    - **Task Instruction**：把你上面写的指令**复制进去**
    - **Attach File（上传文件）**：这里选 **「自动使用最新上传的文件」**（重要）
    
5. 点 **Save** → 定时任务创建完成 ✅

现在：**每天早上 8 点，Manus 会自动拿你最新上传的广告报表，自动分析，自动生成报告。**

---

## 五、第 4 步：怎么让 Manus「自动拿到最新报表」？（小白最关心）

你不用每天手动上传，有 2 种简单办法：

### 办法 A：你每天把报表拖到 Manus 的「文件库」

1. 进入 Manus → **Files（文件）**
2. 每天把亚马逊后台下载的 CSV 拖进去
3. 定时任务会**自动读取最新的那个文件**

### 办法 B：（进阶，不用手动传）用亚马逊自动报表 + 网盘同步

- 亚马逊后台设置：**每天自动发报表到你的邮箱 / Google Drive**
- Manus 可以连接 Google Drive，**自动读取新文件**Manus

小白先用 **办法 A** 最简单。

## 六、第 5 步：自动运行后，在哪里看结果、下载报告？

1. 每次定时任务跑完，会生成一个 **Task Result（任务结果）**
2. 你可以在：
    
    - **Home → Tasks → Completed** 里看到所有历史报告
    
3. 打开报告后：
    
    - 文字：直接复制
    - 表格：复制到 Excel
    - 想保存：全选 → 复制 → 粘贴到 Word/Excel
